# 돌아봄 T06

계획, 할 일, 실행 기록, 돌아보기를 SQLite에 저장하는 한국어 웹 앱입니다. 외부 패키지 없이 Python 표준 라이브러리만 사용합니다. 새 계획이나 작업 예시는 미리 넣지 않습니다. 사용자가 실제로 하는 일을 직접 입력하도록 빈 상태에서 시작합니다.

## 실행

Python 3.10 이상이 필요합니다.

```powershell
python server.py
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. 첫 실행 때 `data/t06.sqlite3` 데이터베이스와 테이블을 자동으로 만듭니다. 서버를 멈춘 뒤 다시 실행해도 이 파일이 남아 있으면 기록이 유지됩니다.

환경 변수:

| 변수 | 기본값 | 설명 |
|---|---|---|
| `T06_HOST` | `127.0.0.1` | 바인딩 주소. 컨테이너나 리버스 프록시 뒤에서는 `0.0.0.0`을 설정합니다. |
| `T06_PORT` 또는 `PORT` | `8000` | HTTP 서버 포트. `PORT`가 우선합니다. |
| `T06_DB_PATH` | `data/t06.sqlite3` | SQLite 파일 경로. 영속 볼륨을 연결해야 합니다. |

## 사용 순서

1. 대시보드에서 실제로 하고 있는 일을 계획으로 저장합니다. 기간, 우선순위, 성공 기준, 예상 시간을 입력합니다.
2. 계획을 열어 할 일을 다섯 개 이상 추가하고, 마감일·우선순위·태그·예상 시간을 채웁니다. 검색과 필터를 사용할 수 있습니다. 목록은 마감일 오름차순, 우선순위 내림차순, 생성 시각 오름차순, ID 오름차순으로 안정 정렬합니다.
3. 할 일을 완료할 때 시작·종료 시각과 실제 시간, 막힘 이유를 기록합니다. 이미 완료된 작업에 완료 요청을 다시 보내도 완료 기록은 추가하지 않습니다.
4. 돌아보기에서 기간을 선택하고 지표를 눌러 계산 근거가 된 할 일과 실행 기록을 확인합니다.
5. 다음 계획을 만든 뒤 돌아보기에서 개선점 한 가지를 해당 계획에 연결합니다.
6. 오른쪽 위 내보내기 버튼으로 전체 데이터를 JSON 파일 하나로 저장합니다.

## 데이터와 집계 규칙

- 계획 수정 전 값은 `plan_revisions`에 스냅샷으로 보존합니다. 변경 이후에도 계획 ID는 유지됩니다.
- 할 일 삭제는 소프트 삭제입니다. 삭제 시각이 기록되고 목록 및 회고 집계에서 제외됩니다.
- 계획 기간이 선택한 회고 기간과 겹치는 계획의 삭제되지 않은 할 일을 회고 대상으로 삼습니다.
- 지연은 현재 상태가 진행 중이고, 마감일이 서울 시간 기준 오늘보다 이전인 할 일만 셉니다.
- 막힘 수는 막힘 이유가 있는 실행 기록을 가진 고유 할 일 수입니다.
- 예상·실제 시간은 분 단위입니다. 실행 시각은 UTC ISO 8601로 저장하며 화면은 서울 시간으로 표시합니다.
- 스크립트 모양 입력은 HTML 텍스트로 이스케이프해 표시합니다. 요청값은 SQL 매개변수로 전달합니다.
- 계획 ID, 수정 스냅샷, 할 일, 실행 기록, 다음 계획 인계는 `contracts/pds-schema-v2.json`에 기록한 계약을 따릅니다.

## 배포

`Dockerfile`로 실행할 수 있습니다. 영속 디스크를 `/app/data`에 마운트하고, 컨테이너의 `T06_HOST=0.0.0.0`을 유지해야 합니다. 공개 주소는 HTTPS를 제공하는 호스팅 환경 또는 리버스 프록시를 통해 연결하세요. 저장소나 데이터베이스 파일을 공개 정적 파일 폴더에 넣지 마세요.

이 과제 버전에는 로그인이나 접근 제어가 없습니다. 공개 URL을 아는 사람은 저장된 기록을 볼 수 있으므로 민감한 내용, 비밀번호, 토큰, 타인의 개인정보를 저장하지 마세요. 사용자 기록은 배포 전에 직접 입력해야 하며, 코드에는 임의의 개인 기록이나 비밀키가 포함되어 있지 않습니다.

## 프로젝트 파일

- `server.py`: SQLite 스키마, JSON API, 정적 파일 서버
- `static/index.html`: 앱 기본 문서
- `static/app.js`: 화면, 입력 폼, 검색·필터·정렬, 회고 상호작용
- `static/styles.css`: 반응형 스타일
- `contracts/pds-schema-v2.json`: 테이블·필드·관계·날짜·집계 계약
- `Dockerfile`: 컨테이너 배포 설정
